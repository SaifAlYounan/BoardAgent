# Mining Exploration Co. trial guide

Use the supplied fictional source pack with four separate people and credential stores:
Rowan Ash is secretary, represented by a management seat with voting weight zero and
secretary authority; Mira Vale is chair with weight one; Tomas Reed and Leila Stone each
have weight one. A separate setup administrator initializes and configures the company,
then ends their temporary voting seat. There must be exactly three ordinary voting seats.

The charter requires two-thirds quorum. Ordinary approval is at least half the yes/no
weight, with every tie rejected; a programme extension above USD 250,000 requires at least
two-thirds of eligible weight. Abstentions count for quorum. Proxies permit a principal's
later own ballot to supersede the proxy ballot. The secretary cannot vote or hold a proxy.
Closing is secretary-confirmed with zero notice and a future deadline. Overrides are
forbidden. Configure these cited rules explicitly through the supported tools; uploading
the charter does not activate them. The setup administrator invites the named members.
This pack does not grant Rowan ordinary member-administration powers.

This sequence has been completed in an isolated synthetic run with scripted
authenticators. Such a run records actual tool results; it does not establish a
persistent local service, real browser acceptance or deployment readiness. See the
[verification register](../../docs/VERIFICATION.md) for the tested scope and limits.

## What an automated run proves

An automated run of these exercises uses real local TLS and MCP calls with separate
cryptographically signed synthetic authenticators and actual supported confirmations. It
can record source hashes, server IDs, audit counts, ballots, minutes lineage, signatures
and action states, with SQL business reads as independent evidence.

That is automated HTTP ceremony evidence. It does not establish actual human acceptance,
third-party client interoperability, persistent account enrollment or deployment. Proxy
supersession, ordinary tie voting, broader feed and search exclusions and full recovery
qualification remain separate acceptance cases. This guide itself is not a pass.
