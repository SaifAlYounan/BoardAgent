# Mining Exploration Co. synthetic trial

This is the source pack and trial sequence for one non-voting secretary and three voting
board members. All people, assets, amounts and charter provisions are fictional.

The [manifest](manifest.json) binds all 16 source files by length and SHA256. The
[trial guide](START-HERE.md) explains their staged use, the four separate roles and the
expected checks. The source documents are inputs; they do not prove account creation,
imports, votes, signatures or a deployed demo. Actual IDs, content hashes and results
belong in your own run records. Credentials and enrollment links never belong
in Git.

The exercises have been run end to end through local TLS and MCP with separate
synthetic authenticators: revised vote and certificate, corrected and signed minutes,
and both separately evidenced actions. Such a run exercises a subset of the tools and
does not cover real human or client acceptance. This pack is source material for your
own run, not a running demo.
